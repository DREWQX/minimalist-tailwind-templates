# Minimalist React + Tailwind CSS Templates (Obsidian UI)

A curated collection of production-ready, zero-bloat web templates built with **React 18, TypeScript, Vite, and Tailwind CSS**.

---

## 1. Obsidian — Dark Mode AI & SaaS Landing Page (Free / PWYW)
High-contrast dark landing page crafted for AI startups, developer tools, and modern SaaS products.
- **Interactive Hero Preview:** Working Overview, Analytics, and Deployments tabs + clickable Execution Graph nodes.
- **3-Column Bento Grid:** Live simulation states, telemetry readouts, and tabbed SDK snippets.
- **Dynamic Pricing:** Monthly/Yearly toggle with automatic 20% discount calculation.

👉 **[Live Preview](https://singular-entremet-b18f29.netlify.app)** | **[Download Template on Gumroad](https://custeredrew.gumroad.com)**

## 2. Canvas — Swiss-Grid Light Mode Portfolio ($19)
Ultra-clean editorial portfolio built for software engineers, product designers, and creative technologists.
- **Filterable Work Grid:** Smooth category filtering (`All`, `Web Apps`, `UI Systems`, `3D & Creative`).
- **Interactive Case Study Modals:** Click any project card for full breakdowns and metrics.
- **One-Click Email Copy & Inquiry Form:** Built-in clipboard copy confirmation and working contact form.
